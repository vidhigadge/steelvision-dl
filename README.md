# SteelVision-DL

A Deep Learning project for steel surface defect analysis under low-resolution imaging conditions.

## Main Research Areas

- CNN-based steel defect classification
- Transfer learning
- Resolution degradation analysis
- Neural super-resolution
- Defect detection and segmentation
- Explainable AI
- Model optimization

## Framework

- Python
- PyTorch
- OpenCV
- torchvision
