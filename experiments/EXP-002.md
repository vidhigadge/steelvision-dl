# EXP-002 — ResNet-50 Transfer Learning

## Objective

Evaluate whether ImageNet pretrained features improve six-class steel surface defect classification compared with the custom CNN baseline.

## Model

ResNet-50 pretrained on ImageNet.

## Transfer Learning Strategy

Feature extraction.

The pretrained ResNet backbone is frozen and only the final classification layer is trained.

## Input

224 × 224 grayscale images converted to 3 channels.

ImageNet normalization is applied.

## Hyperparameters

- Batch size: 32
- Epochs: 10
- Optimizer: Adam
- Learning rate: 0.001
- Loss: CrossEntropyLoss
- Number of classes: 6

## Results

### Test Accuracy

**0.9882 — 98.82%**

### Per-Class Metrics

| Class | Precision | Recall | F1-score | Support |
|---|---:|---:|---:|---:|
| Crazing | 1.00 | 1.00 | 1.00 | 45 |
| Inclusion | 0.94 | 1.00 | 0.97 | 45 |
| Patches | 1.00 | 1.00 | 1.00 | 42 |
| Pitted Surface | 1.00 | 1.00 | 1.00 | 40 |
| Rolled-in Scale | 1.00 | 1.00 | 1.00 | 45 |
| Scratches | 1.00 | 0.92 | 0.96 | 38 |

### Overall Metrics

- Accuracy: **0.9882**
- Macro Precision: **0.99**
- Macro Recall: **0.99**
- Macro F1-score: **0.99**
- Weighted Precision: **0.99**
- Weighted Recall: **0.99**
- Weighted F1-score: **0.99**

## Observations

- ResNet-50 achieved very high test performance with an accuracy of **98.82%**.
- Four classes achieved perfect precision, recall, and F1-score on the test set.
- The `inclusion` class achieved perfect recall but slightly lower precision of **0.94**, indicating that a small number of samples from another class were predicted as inclusion.
- The `scratches` class achieved perfect precision but lower recall of **0.92**, meaning a small number of scratch samples were classified as another defect class.
- The high overall accuracy suggests that pretrained ImageNet features transfer effectively to steel surface defect classification.
- These results should still be compared with the custom CNN baseline before drawing conclusions about the benefit of transfer learning.

## Notes

This experiment uses a pretrained ResNet-50 with the convolutional backbone frozen.

Only the final classification layer is trained on the steel defect dataset.

No full or partial fine-tuning is performed in this experiment.

The next transfer-learning experiment can investigate whether unfreezing part of the ResNet-50 backbone further improves performance.
