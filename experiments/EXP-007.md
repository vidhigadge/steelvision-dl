# EXP-007 — Steel Surface Defect Detection with YOLO26n

## Objective

Train and evaluate an object detection model capable of identifying both:

- the type of steel surface defect
- the spatial location of the defect using bounding boxes

This extends the project from image-level classification to defect localization.

The main research question is:

> Can a pretrained YOLO detector learn to localize and classify steel surface defects using the available YOLO-format annotations?

## Annotation Format

The dataset uses YOLO bounding-box annotations:

```text
class_id center_x center_y width height
```

All bounding-box coordinates are normalized relative to the image size.

Example:

```text
5 0.89 0.6525 0.21 0.685
```

means:

```text
class = scratches
center_x = 0.89
center_y = 0.6525
width = 0.21
height = 0.685
```

## Precision vs Recall

Overall:

```text
Precision = 0.672
Recall = 0.830
```

The higher recall means the detector successfully finds a large proportion of the actual defects.

However, the lower precision indicates that some detections may be false positives.

In this industrial inspection context, relatively high recall can be useful because missing a defect may be more problematic than generating an extra candidate detection.

---

## Understanding mAP

### mAP@50

```text
mAP@50 = 0.801
```

A predicted bounding box is considered correct if its Intersection over Union with the ground-truth box is at least 0.50.

The result indicates strong overall defect detection performance.

### mAP@50-95

```text
mAP@50-95 = 0.505
```

This metric evaluates detection at increasingly strict IoU thresholds from 0.50 to 0.95.

It is therefore much more demanding than mAP@50.

The lower score shows that while the detector usually identifies defects correctly, the exact bounding-box boundaries can still be improved.

## Limitations

- The validation set contains only **30 images**.
- Class-wise results are therefore based on a small number of validation examples.
- Some images contain multiple defect types.
- A few duplicate annotations were present in the raw training labels.
- Only YOLO26n was evaluated in this experiment.
- Detection performance on degraded and super-resolved images has not yet been evaluated.
- A separate held-out detection test set was not available in the current dataset structure.

Because the validation set is small, the reported detection metrics should be interpreted cautiously.

---

## Main Research Finding

The experiment demonstrates that a pretrained lightweight object detector can successfully learn both the class and spatial location of steel surface defects.

The best YOLO26n model achieved:

> **mAP@50 = 80.1% and mAP@50-95 = 50.5%**

with an overall recall of:

> **83.0%**

This shows that the project can move beyond image-level classification toward localized defect analysis.

## Conclusion

YOLO26n successfully learned to detect and localize six types of steel surface defects.

The model achieved strong overall recall and good mAP@50 performance, with particularly strong results for `pitted_surface` and `patches`.

The weaker performance of `rolled_in_scale` indicates that some defect classes remain more challenging.

Overall, the experiment establishes a working object-detection baseline for SteelVision-DL and provides the foundation for later localization and robustness experiments.
