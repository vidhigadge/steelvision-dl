# EXP-009 — Explainable AI with Grad-CAM and SHAP

## Objective

Apply explainable AI methods to the fine-tuned ResNet-50 classifier to investigate which image regions influence steel defect predictions.

Two explanation methods were evaluated:

- Grad-CAM
- SHAP

The purpose of this experiment is not to improve classification accuracy, but to increase interpretability of the trained model.

---

## Model

The explanation methods were applied to the existing fine-tuned ResNet-50 classifier.

Model checkpoint:

```text
models/resnet50_finetune.pth
```

The classifier predicts six steel surface defect classes:

```text
0 = crazing
1 = inclusion
2 = patches
3 = pitted_surface
4 = rolled_in_scale
5 = scratches
```

---

## Test Samples

One test image from each defect class was selected.

The same samples were used for both Grad-CAM and SHAP.

# Grad-CAM

## Method

Grad-CAM produces a spatial heatmap showing which regions of the convolutional feature maps most strongly influence a selected class prediction.

The target layer used was:

```text
model.layer4[-1]
```

This corresponds to the final convolutional block of the ResNet-50 architecture.

The predicted class was used as the Grad-CAM target.

---

## Grad-CAM Pipeline

```text
input image
↓
ResNet-50
↓
predicted class
↓
gradients from predicted class
↓
final convolutional feature maps
↓
Grad-CAM heatmap
↓
overlay on original image
```

# SHAP

## Method

SHAP was used as a complementary feature-attribution method.

Unlike Grad-CAM, which operates using convolutional activation maps, SHAP estimates how input regions influence a model prediction relative to a reference background.

The implementation used:

```text
shap.GradientExplainer
```

---

## SHAP Background

A small background dataset was created using:

```text
2 training images × 6 classes
= 12 background images
```

The background provides the reference against which feature contributions are estimated.

---

## SHAP Pipeline

```text
test image
+
background images
↓
ResNet-50
↓
GradientExplainer
↓
feature attribution
↓
absolute attribution heatmap
↓
overlay on image
```

# Grad-CAM vs SHAP

The two methods provide related but different explanations.

## Grad-CAM

Grad-CAM answers approximately:

> Which spatial regions in the CNN feature maps were important for this class prediction?

Advantages:

- computationally efficient
- produces intuitive spatial heatmaps
- well suited to convolutional neural networks

Limitations:

- explanation resolution is limited by the convolutional feature-map resolution
- explanations depend on the selected layer
- highlighted areas should not automatically be interpreted as causal evidence

---

## SHAP

SHAP answers approximately:

> Which image regions contributed to the prediction relative to the selected reference background?

Advantages:

- provides feature-attribution information
- offers a complementary interpretation to Grad-CAM
- explicitly compares predictions against a baseline

Limitations:

- more computationally expensive than Grad-CAM
- results depend on the background dataset
- image attribution maps can be visually noisy
- attribution does not necessarily imply physical or causal importance

---

# Interpretation

Both explanation methods successfully generated spatial attribution maps for all six steel defect classes.

Because the selected examples were classified correctly with high confidence, the heatmaps allow qualitative investigation of whether the model's attention overlaps visually meaningful defect regions.

However, these visual explanations should be treated as model interpretation tools rather than proof that the model has learned the true physical mechanism underlying each defect.

---

# Relationship to Detection

The project now contains two different forms of spatial information.

Classification explainability:

```text
image
↓
ResNet-50
↓
defect class
↓
Grad-CAM / SHAP
↓
important image regions
```

Object detection:

```text
image
↓
YOLO
↓
defect class
+
explicit bounding box
```

Grad-CAM and SHAP explain classification behavior, while YOLO directly predicts defect locations.

Comparing these forms of spatial information can later help identify whether classification attention is consistent with detected defect locations.

---

# Limitations

- Only one example from each class was visualized.
- Heatmaps were evaluated qualitatively rather than with a quantitative localization metric.
- SHAP results depend on the selected background images.
- Grad-CAM results depend on the selected convolutional layer.
- High prediction confidence does not guarantee reliable explanations.
- Explanation maps are not equivalent to ground-truth defect segmentation.
- Neither Grad-CAM nor SHAP establishes causal relationships.

---

# Main Finding

SteelVision-DL can now provide visual explanations for its ResNet-50 classification predictions using two complementary XAI techniques.

Grad-CAM provides convolutional spatial activation explanations, while SHAP provides gradient-based input attribution relative to a training-image background.

Together, these methods improve model transparency without changing the trained classifier.

---

# Conclusion

Phase 9 successfully integrated Grad-CAM and SHAP into the SteelVision-DL pipeline.

Both methods generated explanation maps for all six steel surface defect classes, while the selected test samples remained correctly classified with high confidence.

These explainability components provide a foundation for later reliability analysis and for comparing classification attention with explicit defect localization.
