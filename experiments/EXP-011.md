# EXP-011 — Model Export, Optimization, and Quantization

## Objective

Evaluate deployment-oriented optimization methods for the fine-tuned ResNet-50 classifier.

The experiment focused on:

- exporting the PyTorch model to ONNX
- verifying numerical equivalence between PyTorch and ONNX
- comparing inference latency
- testing post-training INT8 quantization
- evaluating the trade-off between model size and classification accuracy

---

Model:


# CPU Inference Benchmark

A CPU-to-CPU benchmark was performed to avoid mixing backend performance with hardware acceleration.

Both models used the same:

```text
input image
224 × 224 resolution
CPU execution
```

Benchmark configuration:

```text
20 warm-up runs
100 timed inference runs
```

Results:

```text
PyTorch CPU latency = 19.883 ms/image
ONNX CPU latency    = 12.590 ms/image
```

ONNX speedup:

```text
1.58×
```

This demonstrates that ONNX Runtime provided faster CPU inference than the standard PyTorch CPU backend for this model and hardware configuration.

# Post-Training INT8 Quantization

Post-training static quantization was investigated to reduce model size.

The FP32 ONNX model was approximately:

```text
90 MB
```

Quantized models were approximately:

```text
23 MB
```

This represents a model size reduction of approximately:

```text
74%
```

However, quantization introduced significant accuracy degradation.

---

# INT8 Experiment 1 — Initial QInt8 Quantization

Configuration:

```text
QDQ quantization
signed INT8 activations
signed INT8 weights
per-channel quantization
60 calibration images
```

Results:

```text
FP32 accuracy = 0.9922
INT8 accuracy = 0.9294
```

Accuracy difference:

```text
-0.0627
```

or approximately:

```text
-6.27 percentage points
```

FP32 / INT8 prediction agreement:

```text
0.9216
```

Mean confidence difference:

```text
0.113049
```

Although model size was reduced substantially, the accuracy loss was considered too large for the current deployment pipeline.

# Main Finding

The FP32 ONNX model provided the best overall deployment trade-off.

It:

```text
preserved classification accuracy
+
matched PyTorch predictions closely
+
improved CPU inference latency
```

The measured CPU speedup was:

```text
1.58×
```

without reducing test accuracy.

---

# Quantization Finding

INT8 quantization successfully reduced model size from approximately:

```text
90 MB
```

to:

```text
23 MB
```

However, every tested post-training quantization configuration caused substantial classification accuracy degradation.

Therefore:

```text
smaller model
≠
better deployment model
```

for the current ResNet-50 pipeline.

---

# Deployment Decision

The selected deployment candidate is:

```text
FP32 ONNX ResNet-50
```

rather than the INT8 versions.

Reasons:

- preserves 99.22% classification accuracy
- numerically matches the PyTorch implementation
- provides approximately 1.58× faster CPU inference
- supports portable runtime deployment
- avoids the large accuracy degradation observed with INT8 models

---

# Limitations

- Latency was measured on one Apple M4 system.
- Benchmarking used batch size 1.
- Only CPU ONNX Runtime inference was evaluated.
- INT8 calibration datasets were relatively small.
- Quantization-aware training was not evaluated.
- Layer-wise quantization sensitivity analysis was not performed.
- Hardware-specific acceleration may produce different results on other systems.
- Model size measurements are approximate filesystem values.

---

# Future Optimization Options

Possible future work includes:

- quantization-aware training
- selective layer quantization
- model distillation
- pruning
- smaller backbone architectures
- hardware-specific inference providers
- additional ONNX graph optimization

These techniques could provide further efficiency improvements while attempting to preserve classification accuracy.

Phase 11 successfully exported and optimized the SteelVision-DL classification model for deployment.

The FP32 ONNX version preserved the original model's prediction quality while reducing CPU inference latency from:

```text
19.883 ms/image
```

to:

```text
12.590 ms/image
```

for a measured speedup of:

```text
1.58×
```

Post-training INT8 quantization reduced model size by approximately 74%, but the associated accuracy loss was unacceptable.

The FP32 ONNX model was therefore selected as the preferred deployment representation for later SteelVision-DL application stages.
